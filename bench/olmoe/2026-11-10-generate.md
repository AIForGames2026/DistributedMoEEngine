# OLMoE-1B-7B token generation on the desktop (2026-11-10)

First TASK-24 results: generation with a KV cache, one token at a time, checked against transformers' greedy `generate()`. These are desktop runs. The acceptance run (RDMA on `gx10-03`, 10 minutes) is still to do.

## Setup

- Desktop, WSL2 Ubuntu 24.04, RTX 5070 Ti (compute 12.0, 16 GB), `olmoe` built ReleaseFast with `-Dgpu=true`, `--gpu`.
- Model: OLMoE-1B-7B-0924-Instruct, Q8_0 GGUF (7.36 GB).
- Reference: `tools/ref/ref_olmoe.py --generate 64` recorded 64 greedy tokens per golden prompt from transformers 4.57.1 (float32, eager attention, CPU) on the same Q8_0 weights, with no stop at end-of-text, plus the logits each token was picked from. It took 6.6 minutes on the desktop CPU.
- Command: `olmoe local|shm MODEL --golden olmoe_generate.tfref --gpu --generate 64` (`--payload f32` for `shm`).
