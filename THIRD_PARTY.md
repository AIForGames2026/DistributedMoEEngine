## ggml (llama.cpp), MIT

From [llama.cpp](https://github.com/ggml-org/llama.cpp) at commit `ffc87c3a7989cb657641a6459a186f303e176af8` (Nov 18, 2026), TASK-36:

| File | What | How |
|---|---|---|
| `src/iq_tables.zig`, `csrc/cuda/iq_tables.cuh` | The IQ formats' lookup tables (`ksigns_iq2xs`, `iq2xxs_grid`, `iq2xs_grid`, `iq2s_grid`, `iq3xxs_grid`, `iq3s_grid`, `iq1s_grid`, `kvalues_iq4nl`) from `ggml/src/ggml-common.h` | Generated by `tools/ref/gen_iq_tables.py`; each file carries the notice below |
| `src/quant.zig` (the formats added in TASK-36) | Ports of ggml's reference `dequantize_row_*` for Q4_1, Q5_0, Q5_1, Q2_K, Q3_K, Q5_K, Q6_K, IQ1_S, IQ1_M, IQ2_XXS, IQ2_XS, IQ2_S, IQ3_XXS, IQ3_S, IQ4_NL and IQ4_XS, from `ggml/src/ggml-quants.c` | Ported to Zig with the same order of float operations |
| `csrc/cuda/blocks.cuh` | The same decoding, per 8 values, for the GPU kernels | Written from the ports above |

The block layouts of the formats that came earlier (Q8_0, Q4_0, Q4_K, MXFP4, NVFP4) follow ggml's as well.
