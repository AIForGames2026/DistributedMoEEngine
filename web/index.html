Recorded on real hardware (Nov 5 to 11, not simulated)

  • Two DGX Sparks over RDMA: OLMoE-1B-7B split across them writes 54.4 tokens/s for 40 minutes, 2.7x one Spark, every round identical (raw results)
  • The split matches Hugging Face's own code: every top token, and all 192 generated tokens (raw results)
  • RDMA between the Sparks: 4.4 µs one way, 1.3x the hardware's own test (raw results)
  • Lookahead: guesses 83.6% of the experts two layers ahead, with output unchanged; 30 minutes with 10% of guesses forced wrong never changed a token (raw results)
  • Tracker: a killed machine is marked unhealthy in 52 ms, and the router stops sending it tokens (raw results)
  • Mixed machines: a desktop CPU with no GPU, and a laptop RTX 3060, each run half of the experts with every top token matching (CPU, laptop)
  • Qwen3-30B-A3B reads a 131,040-token prompt (about a novel) on one Spark: first word in 510 s, then 0.18 s per word; with most of its memory moved to disk, the output is identical (raw results)
  • Saved prompts: the same 131,040-token prompt a second time reaches its first word in 4.2 s instead of 510 s, with identical output (raw results)
