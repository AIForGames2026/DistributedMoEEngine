# Chat replay: GLM-5.3-Flash across two DGX Sparks over RDMA (TASK-32, 2026-11-20)

This is a recording for the public page, of GLM-5.3-Flash (ggml-org's Q4_K GGUF, 181 GB) split between `gx10-02` and `gx10-01`. It is the same scripted three-turn chat as the other replays (`tools/ref/record_chat.py`): temperature 0, reasoning on at `reasoning_effort` low, up to 1,200 tokens per reply. It was recorded in the second two-Spark window, written up in `bench/olmoe/2026-11-17-glm53.md`.

Setup:

- **Commands:** rank 0 is `olmoe rdma-router MODEL --peer rdma:192.168.177.11:PORT@rocep1s0f1 --gpu --serve 127.0.0.1:8093 --ctx 16384 --record FILE` on `gx10-02`, and rank 1 is `olmoe rdma-expert MODEL --port PORT --dev rocep1s0f0 --rank 1 --ranks 2 --gpu --max-step 2048` on `gx10-01`, both engine build `v0.2.0-alpha-45-g5204040-g32m`, linked over RDMA on the direct cable.
- **Placement:** rank 0 runs the attention layers, the routers and experts 0 to 143 of each layer; rank 1 runs experts 144 to 287. Every expert is in memory (95.8 GB resident on rank 0, 85.6 GB on rank 1), so the recording has no expert cache or prefetching.
- **Chat format:** `glm`. Each reply starts on the reasoning channel.
- **Files** (in `2026-11-20/`):
  - `chat-glm53-two-sparks.jsonl.gz` is the recording.
  - `chat-glm53-two-sparks.log` is rank 0's log, and `chat-glm53-two-sparks.expert.log` rank 1's.
  - `chat-glm53-two-sparks.txt` is the client's transcript, which shows the first 300 characters of each reply.

**The recording:**

- **Steps:** 287 in all (three prefills and 284 decode steps), none dropped.
- **Expert calls:** 197,568: 98,436 on `gx10-02` and 99,132 on `gx10-01`, matching each rank's own counters.
- **Replies:** all three finished on their own, well inside the 1,200-token limit, with no non-finite GPU output on either rank.

**The third turn reused no prompt tokens,** so it prefilled all 259 tokens, which is why its first token took 13.0 s. The second turn reused 116 of its 137.

## The page

The page plays the recording at its recorded speed.

- **Dense layers:** GLM-5.3-Flash's first 3 layers run no experts, so a token runs 8 experts in 42 of its 45 layers, 336 in all. All experts' title counted every layer (360); it now counts the layers that ran experts, which leaves the other recordings' titles as they were.
- **Turn 1 has no reasoning:** at effort low, GLM answered the first question directly; turns 2 and 3 reason briefly first.
- **Checked:** at desktop and phone widths, with no console errors, and the per-rank counts match the engine's own as it plays.
