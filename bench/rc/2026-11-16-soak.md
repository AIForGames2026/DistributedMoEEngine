# One-hour soak and cross-machine run (TASK-15, 2026-11-16)

TASK-15 acceptance runs, both recorded with `--record` (TASK-16). The task named `gx10-03`; both runs used `gx10-02` instead, which was otherwise idle, so nothing had to be agreed with `gx10-03`'s co-tenant.

Raw logs, load samples, versions, recordings, and the scripts that ran them are in [`2026-11-16-soak/`](2026-11-16-soak/). Build: commit `d3c271c` (`v0.2.0-alpha-26-gd3c271c`), ReleaseFast with `-Dgpu=true`, plus `-Drdma=true` on `gx10-02`. `gx10-02`: kernel 7.0.0-1019-nvidia, driver 580.178.04, Zig 0.17.0. Desktop: WSL2 kernel 6.6.87.2, RTX 5070 Ti, driver 617.42.

Model: OLMoE-1B-7B-0924-Instruct, Q8_0 (7.4 GB), every expert loaded, F32 payload, GPU matmuls on both ranks. Rank 0 holds attention, the router, the LM head, and experts 0 to 31 of each layer; rank 1 holds experts 32 to 63. Each run first checks the three golden prompts against transformers and the first 64 generated tokens of each against `generate()`, then repeats generation (`--generate 64 --minutes M`), and every round must give round 1's tokens and logits bit for bit.

## Soak: two engine processes on `gx10-02` over RDMA, 1 hour

`soak.sh 60`: `olmoe rdma`, which forks rank 1 and links the two processes over RDMA loopback on the Spark's ConnectX-7.

| Measure | Target | Result |
|---|---|---|
| Throughput | at least 10 tokens/s aggregate | **30.8 tokens/s**: 110,784 tokens in 60.0 minutes, 577 rounds; rounds 30.0 to 30.9 (494 of them at 30.8) |
| Crashes | none | **none**: both processes exited 0 after 1:00:12 |
| Resident memory | under 1% drift after warm-up | **+0.00%**: rank 0 4,194 MB after round 1 and at most 4,194 MB (its own report); sampled each minute, rank 0 stayed at 4,096,020 KB and rank 1 at 3,463,584 KB from minute 1 to minute 60 |
| Correctness | | prompt logits within 5.05e-5 of transformers, every top-1 and expert choice identical, 192 of 192 tokens equal to `generate()`; all 577 rounds identical to the first; both ranks' weights in memory unchanged at exit |

**Expert calls:** 8,761,889 were run on rank 0 and 8,407,903 sent to rank 1.

**Machine:** GPU utilization was 86 to 91% throughout. Nothing else ran beyond the system's own agents (`k3s-agent` and `dcgm-exporter`, about 2% CPU each). Free memory stayed between 110.9 and 118.8 GB.

**Against earlier runs:** this is 1.5 times the 20.5 tokens/s of the same one-node setup on Nov 11 (TASK-15b). The engine has changed a lot since then; which change made the difference was not measured.

**Recording:** 110,979 steps, none dropped, gapless. The per-rank sums from its frames equal the engine's counters exactly (`tools/ref/check_trace.py`). It is 139 MB as written, archived as `soak.jsonl.xz` (6.7 MB). The page reads JSONL or gzip, so convert it before replaying:

```bash
xz -dc soak.jsonl.xz | gzip -9 > soak.jsonl.gz
```

That gives 24 MB.

**Replay in the page** (browser pane on the desktop, Chromium, 144 Hz display):
- **Loading:** the gzipped file loaded and parsed in 0.71 s.
- **Frame rate:** 144 frames per second at 1x and at 10x, 6.9 ms per frame at p50 and 7.1 at p99.
- **Seeking:** 47 to 331 ms, depending on how far into the hour it rebuilds.
- **Counts:** at the end, the page's per-rank counts read 8,761,889 and 8,407,903, matching the engine. Both ranks are labelled `GX10-02`.

## Cross-machine run: desktop and `gx10-02` over TCP, 10 minutes

`cross.sh 10`:
- **Rank 0:** runs in WSL2 on the desktop (RTX 5070 Ti, 3.94 GB copied to the GPU).
- **Rank 1:** runs on `gx10-02` (`olmoe expert`).
- **Connection:** rank 0 dials rank 1's Tailscale address. Dialing out from WSL2 needs no forwarder, unlike TASK-21 and TASK-26, where the Spark dialed in.

| Measure | Result |
|---|---|
| Correct tokens | **yes**: prompt logits within 5.05e-5 of transformers, every top-1 and expert choice identical; 192 of 192 tokens equal to `generate()`; both rounds of the soak identical to the first; both ranks' weights unchanged; both exited 0 |
| Duration | 10.3 minutes of repeated generation after the checks |
| Throughput (not targeted) | 0.6 tokens/s; each 64-token generation took 101 to 102 s |
| Memory | rank 0 reported 4,203 MB after round 1 and at most 4,203 MB |
| Recording | 579 steps, none dropped, gapless; per-rank calls 48,339 / 46,253 equal the engine's (`cross/cross.jsonl.gz`, 149 KB) |

**The link was Tailscale's DERP relay in New York, not a direct path.**
- `tailscale ping` reported a direct path (2 ms) once before the run. Afterward it reported "direct connection not established" and 34 ms via DERP.
- Pings sampled each minute during the run read 31 to 35 ms.
- At about 100 ms per layer for 16 layers, each token waits on a few relay round trips. This is the relay-bound case TASK-21 said to label.
- The direct campus TCP path from TASK-21 needs the Spark to dial the desktop, with a forwarder on Windows. That was not used.
