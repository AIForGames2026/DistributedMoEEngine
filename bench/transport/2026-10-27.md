# Transport check: shared memory and TCP (2026-10-27)

TASK-02 acceptance run. `dispatch` (ReleaseFast) sends 4,096 dispatch packets from rank 0 to rank 1; rank 1 verifies each and sends a combine packet back; rank 0 verifies every combine. Every packet is checked for CRC32C, slot generation, and payload contents. 64 slots per ring, 7,552-byte packets.

| Backend | Machines | Time | Per token (pipelined) | Both directions | Result |
|---|---|---|---|---|---|
| Shared memory | `gx10-03`, two processes | 7.4 ms | 1.81 us | 66.6 Gb/s | all verified |
| Shared memory | WSL2 desktop, two processes | 12.6 ms | 3.07 us | 39.3 Gb/s | all verified |
| TCP loopback | `gx10-03` | 46.2 ms | 11.3 us | 10.7 Gb/s | all verified |
| TCP loopback | WSL2 desktop | 42.1 ms | 10.3 us | 11.8 Gb/s | all verified |
| TCP over Tailscale | WSL2 desktop to `gx10-03` | 27.4 s | 6,695 us | 0.02 Gb/s | all verified |

Unit tests also cover ring wraparound, a corrupted slot (reported as a protocol error), and withheld credits: with 4 slots and no credits returned, the 5th send returns `WouldBlock` and the receiver still reads the original 4 packets untouched.

Notes:

- **Shared-memory cost is mostly CRC and copies**, not signaling: each token is two 7,552-byte copies and four CRC passes. Before switching CRC32C to the ARMv8 CRC instructions (`csrc/tf_crc32c.c`), `gx10-03` took 30 us per token with Zig's table-based CRC.
- **The desktop-to-Spark path is relayed.** `tailscale ping` shows no direct connection; traffic goes through the DERP relay in NYC at about 33 ms round trip, and the relay limits bandwidth. The number above measures the relay, not the transport. A direct path (UDP 41641 reachable at either end) should be tried before the RC cross-machine run (TASK-18).
- **Found and fixed on the relayed path:** the router sometimes lost the last few dozen combines (4,061 of 4,096) when the expert closed its socket. Something on the relayed path re-terminates TCP, so close-time behavior cannot be trusted. Endpoints now exchange an explicit goodbye (`Endpoint.finish`) before closing, which RDMA will need anyway.
- Co-tenant on `gx10-03`: vLLM resident, GPU idle.
