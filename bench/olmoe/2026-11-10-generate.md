# OLMoE-1B-7B token generation (2026-11-10)

TASK-24 acceptance run: generation with a KV cache, one token at a time, checked against transformers' greedy `generate()`. It ran over RDMA on `gx10-03`, with desktop runs alongside for comparison.

## Setup

- Model: OLMoE-1B-7B-0924-Instruct, Q8_0 GGUF (7.36 GB).
- Reference: `tools/ref/ref_olmoe.py --generate 64` recorded 64 greedy tokens per golden prompt from transformers 4.57.1 (float32, eager attention, CPU) on the same Q8_0 weights, with no stop at end-of-text, plus the logits each token was picked from. It took 6.6 minutes on the desktop CPU. The file was copied to `gx10-03` and its SHA-256 checked.
- `gx10-03`: GB10 (compute 12.1), `olmoe` built there ReleaseFast with `-Drdma=true -Dgpu=true`. Two processes over RDMA loopback, F32 payload. Rank 0 held the non-expert weights and experts 0 to 31, and rank 1 held experts 32 to 63. The co-tenant used 106 of the machine's 121 GB during the run.
- Desktop: WSL2 Ubuntu 24.04, RTX 5070 Ti (compute 12.0, 16 GB), built ReleaseFast with `-Dgpu=true`.
- Command: `olmoe rdma|shm|local MODEL --golden olmoe_generate.tfref --payload f32 --gpu --generate 64`, plus `--minutes 10` for the memory run.
